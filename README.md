# Sports Nest

Sports Nest is a modern sports management and booking platform where users can explore sports facilities, book venues, and manage activities easily.

---

## Features

- User Authentication
- Google Login
- JWT Authentication
- Sports Facility Management
- Booking System
- Protected Routes
- Responsive UI
- Dashboard System
- MongoDB Database Integration

---

## Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS
- DaisyUI

### Backend
- Node.js
- Express.js
- MongoDB

### Authentication
- Better Auth
- JOSE (JWT)
- Google OAuth
